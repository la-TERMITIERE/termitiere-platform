# 🧪 Les Labs — Travaux Pratiques (TP)

Bienvenue dans la partie **pratique** de l'academy. La théorie, c'est les cours ; ici, on
**fait**. Chaque lab est un **TP guidé** avec : un objectif, le matériel, des étapes pas à pas,
du **code complet**, la **solution corrigée**, les erreurs fréquentes, et un **QCM**.

## Comment faire un lab
1. Lis l'**objectif** et vérifie les **prérequis**.
2. Fais les étapes **toi-même** d'abord (c'est en faisant qu'on apprend).
3. Bloqué ? Regarde la **solution** — mais essaie avant.
4. Termine par le **QCM** pour vérifier que c'est compris.

## Niveaux de difficulté
🟢 Débutant · 🟡 Intermédiaire · 🔴 Avancé

## ⚠️ Règle d'or : NE PAS apprendre sur la production
Pour les labs qui touchent à une base, **ne travaille jamais sur ta vraie base** (`tp/` du projet
`max-agro-83baf`). Deux options propres :
- **(Recommandé)** Crée un **projet Firebase « bac à sable »** gratuit, dédié aux exercices
  (console Firebase → *Ajouter un projet* → `termitiere-sandbox`). Tu casses ce que tu veux, ça
  n'affecte rien.
- **(À défaut)** Travaille sous un nœud `lab/` séparé, et **supprime-le** à la fin.
